# TEN-193 — [P1] The Clerk identity fetch has no timeout, so a searched people page hangs
status: Backlog
url: https://linear.app/tenken/issue/TEN-193/p1-the-clerk-identity-fetch-has-no-timeout-so-a-searched-people-page

**What breaks.** `lib/server/identity.ts:104` awaits `fetcher(...)` with `cache: "no-store"` and no `signal`. It is called from the search path in `features/people/load.ts` and from `resolveIdentity` at `app/(dashboard)/people/page.tsx:71`.

**Evidence.** `lib/server/identity.ts:104`. The module has a refusal state to render; nothing bounds the wait that would reach it.

**Blast radius.** `/people` with `?q=` or `?who=`, which is the point of the page.

**How to know it is fixed.** An abort signal on the fetch. With a never-resolving fetcher, `searchClerkUsers` returns its refused state inside the deadline and the no-logging test still passes.
