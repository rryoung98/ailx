# TEN-128 — Report stays locked after a finished run, and 'Scores of record' is always empty
status: In Review
url: https://linear.app/tenken/issue/TEN-128/report-stays-locked-after-a-finished-run-and-scores-of-record-is

**Observed 2026-09-04, live run** `856b850c-51ac-4a1a-82a5-24deb8df66ae`**, finalized at 07:39:30Z.**

/report shows, permanently:

> The report is the reward — **3 of 4 tracks scored. Finish the run to unlock it.** [Continue ->]
> Scores of record — The exam service returned no scores for this attempt, so this panel shows none.

Two separate defects:

1. **The unlock gate reads the LOCAL event log only.** T2 was later scored by the service (`POST /v1/attempts/:id/score` -> 200, scaled 30.83), but nothing writes that into the browser's log after the run screen is gone, so the gate stays at 3 of 4. "Continue ->" goes back to /exam, which says the run is complete and links back to the locked report. Closed loop, no exit.
2. `GET /v1/attempts/:id` **returns no** `scores` **field** even after the service issued T2 and T3 scores. `packages/contract/src/routes.ts` documents `scores?: AttemptScores` on that read, and the panel exists to display it. It can never populate today.

**Effect:** a candidate finishes a full four-track sitting and receives nothing.
