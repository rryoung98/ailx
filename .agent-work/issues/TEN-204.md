# TEN-204 — [P2] Any allowlisted tab can bypass the board memo with a query parameter and stampede Linear
status: Backlog
url: https://linear.app/tenken/issue/TEN-204/p2-any-allowlisted-tab-can-bypass-the-board-memo-with-a-query

**What breaks.** `app/api/board/route.ts:23-24` reads `force` straight from the query string, and `lib/server/boardCache.ts:41-42` makes a forced read skip both the TTL entry and the in-flight share. N concurrent forced reads are N cold board reads of up to 21 Linear requests each, against a stated budget of 2500 an hour (`lib/linearBoard.ts:38`).

**Evidence.** `app/api/board/route.ts:23-24`, `lib/server/boardCache.ts:41-42`, `lib/linearBoard.ts:38` and `:238`.

**Blast radius.** The Linear API key shared by this dashboard. A rate limit there takes the board and the sprint panel down together.

**How to know it is fixed.** A forced read skips the TTL and still joins an in-flight read, or the parameter goes. Two concurrent forced reads produce one fetch.
