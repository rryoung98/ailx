# TEN-124 — One SaveConflictError poisons persistence for the rest of the sitting
status: Backlog
url: https://linear.app/tenken/issue/TEN-124/one-saveconflicterror-poisons-persistence-for-the-rest-of-the-sitting

`packages/session/src/persist.ts:60-70`. After a single `SaveConflictError` the persistence layer stops saving for the remainder of the sitting, locally and server-side, and the report then reads the stale `localStorage` log.

A candidate finishes a run and gets a report built from a log that stopped growing at the conflict - which is a score computed from partial evidence, presented as a score.

Do: recover rather than latch - re-read the stored log, re-derive from the current revision, and if the conflict cannot be resolved, stop the clock and say so instead of continuing to accept work that is not being saved.
