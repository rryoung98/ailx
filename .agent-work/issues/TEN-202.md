# TEN-202 — [P2] The board poll has no timeout and no overlap guard
status: Backlog
url: https://linear.app/tenken/issue/TEN-202/p2-the-board-poll-has-no-timeout-and-no-overlap-guard

**What breaks.** `features/board/useBoard.ts:159` fetches with no signal, and `:131` starts a `setInterval`. The `pending` ref at `:57` counts moves only, so a tick starts a new refresh while the previous one is still open. With the missing Linear timeout, a tab accumulates hanging connections and `syncing` never clears.

**Evidence.** `features/board/useBoard.ts:57`, `:131`, `:159`.

**Blast radius.** Every open board tab, one stacked request per minute, and a spinner that never stops.

**How to know it is fixed.** An in-flight flag plus an abort signal. With a fetch stub that never resolves and fake timers advanced ten intervals, exactly one request is open.
