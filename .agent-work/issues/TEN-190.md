# TEN-190 — [P1] The claim more than one bank version has been served renders yes when only one has
status: In Review
url: https://linear.app/tenken/issue/TEN-190/p1-the-claim-more-than-one-bank-version-has-been-served-renders-yes

**What breaks.** `fromCount()` in `lib/truth.ts` sets the verdict from `n > 0`, and one of the claims it drives says "More than one bank version has been served". With a single distinct `bank_sha256` the panel renders YES for a sentence that says more than one.

**Evidence.** `lib/truth.ts` `fromCount()` and the `banksServed` check; `TRUTH_COUNTS_SQL` counts `count(DISTINCT bank_sha256) FROM attempt_decks`. The store returns 2 today, so the row is true by luck. It was false while the store held one digest, and it will be false again for any store seeded from one bank.

**Blast radius.** The truth page and the bank rotation argument that reads it.

**How to know it is fixed.** The threshold matches the sentence: yes at two or more, no at one, count shown either way. A fixture with one digest renders no.
