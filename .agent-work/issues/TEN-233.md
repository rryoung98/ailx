# TEN-233 — [P2] The partial-sitting share is offered although no partial payload shape exists
status: Backlog
url: https://linear.app/tenken/issue/TEN-233/p2-the-partial-sitting-share-is-offered-although-no-partial-payload

**What breaks.** The report offers the share panel to a partial sitting and the panel promises a partial card, but `SharePayload` requires a band, a player type and all four track scores, and the builder returns null for a run that is not fully scored. The reader renders every field unconditionally.

**Evidence.**
Offer: `apps/web/app/report/page.tsx:309-311`; promise: `features/report/ShareLink.tsx:244-248`. Shape: `packages/report/src/share.ts:161-189` (required `band`, `playerType`, `tracks: Record<TrackId, number>`) and `buildSharePayload` returns null when the run is not fully scored (`:232-238`). Reader: `features/share/ShareView.tsx:121,124,130-131` (`p.tracks[t].toFixed(1)` for every track) and `app/s/[token]/page.api.tsx:49-50` builds the OG title from `p.playerType.code`. `apps/web/test/finishedSitting.test.tsx:303-326` tests the button copy only, not that the button works.

**Blast radius.** Every candidate who sits without a model connected, which is the documented no-model path. Either the create is refused and reported as a blip, or a stranger's `/s/<token>` throws and the unfurl is broken.

**Fixed when.** Either the panel is not offered for a partial sitting, or `SharePayload` gains a partial arm that the view and `generateMetadata` both branch on, with an end-to-end test.
