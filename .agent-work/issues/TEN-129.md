# TEN-129 — Run hub says 'All four tracks are scored' when two were not
status: In Review
url: https://linear.app/tenken/issue/TEN-129/run-hub-says-all-four-tracks-are-scored-when-two-were-not

**Observed 2026-09-04 on the live run hub after finalize.**

The completion screen reads: *"Run complete. All four tracks are scored. The diagnostic report is the real reward."*

Directly beneath it, on the same screen: *"the server has not issued your T3 score yet: ... failed: 409"*, and the track list showed T2 and T3 as "recorded, not scored".

The screen states a falsehood the screen itself contradicts. In an instrument that sells honesty about what it can and cannot claim, this is the copy that must not ship.

**Fix direction:** derive the sentence from the scored-track count, and name the unscored tracks.
