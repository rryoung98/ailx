# TEN-127 — Only the LAST failed track can be retried — T2 stays unscored forever
status: In Review
url: https://linear.app/tenken/issue/TEN-127/only-the-last-failed-track-can-be-retried-t2-stays-unscored-forever

**Observed 2026-09-04, live run** `856b850c-51ac-4a1a-82a5-24deb8df66ae`**.**

`scoreRetryRef` in `apps/web/app/exam/page.tsx` holds ONE `{attemptId, trackId, artifact}`. T2 failed first (409), then T3 failed and OVERWROTE it. The single **Retry scoring** button therefore rescored T3 only. T2's retry, and its error banner, were silently lost — the hub showed just the T3 error, then no error at all.

Result: a completed, finalized run with 3 of 4 tracks scored and no way in the UI to score the fourth. The report never unlocks (see the linked report issue).

**Fix direction:** keep a per-track queue of failed scores and retry all of them; show one banner per unscored track.
