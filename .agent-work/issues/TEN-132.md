# TEN-132 — Finished practice never reaches /progress, and the two pages contradict each other
status: In Review
url: https://linear.app/tenken/issue/TEN-132/finished-practice-never-reaches-progress-and-the-two-pages-contradict

**Observed 2026-09-04 on staging (live).**

Finish a practice round: the summary says "1 day streak / 1 days practised", and `localStorage.ailx:practice:v1` holds the day.

Open /progress seconds later: "No practice days behind you yet". Its method line claims "practice answers graded on the server".

Anonymous practice is never POSTed to the service, so /progress can only ever show zero while practice promises a streak. Two surfaces state opposite things about the same act, and the progress page describes a server grading step that did not happen.

Found by the public-surface sweep during the 2026-09-04 dogfood.
