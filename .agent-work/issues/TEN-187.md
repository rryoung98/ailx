# TEN-187 — [P1] The Clerk lookup in the middleware has no deadline
status: Backlog
url: https://linear.app/tenken/issue/TEN-187/p1-the-clerk-lookup-in-the-middleware-has-no-deadline

**What breaks.** `middleware.ts:32-33` awaits `clerkClient()` then `client.users.getUser(userId)` with no timeout. The SDK sets none. This runs before anything else on every gated request, so a slow Clerk is a hard stop ahead of the database and the page.

**Evidence.** `middleware.ts:32-33`; the same pattern at `lib/server/admin.ts:50-51`.

**Blast radius.** Every page and both API routes. `/sign-in`, `/denied` and `/locked` still answer, so the deploy looks half alive rather than down.

**How to know it is fixed.** The lookup races an abort at a few seconds and a timeout is a refusal with its own sentence. With a client that never resolves, the request completes inside the deadline.
