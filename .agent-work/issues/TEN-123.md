# TEN-123 — Nothing wires onSyncError - a hosted sitting can fail to mirror for its whole duration, silently
status: Backlog
url: https://linear.app/tenken/issue/TEN-123/nothing-wires-onsyncerror-a-hosted-sitting-can-fail-to-mirror-for-its

`apps/web/lib/data/persistence.ts:195` declares `onSyncError` and `:683` never passes one. So every mirror failure during a hosted sitting is swallowed.

`FRONTEND.md` §1: *"offline -> visible state"*. A candidate can sit a full run whose event log never reached the service, with nothing on screen saying so, and discover it only when the report cannot find their attempt.

Do: wire `onSyncError` in `browserApiOptions()` to a persistent, non-dismissable "not saved" indicator in the exam chrome, next to `PersistWarning`, and clear it on the next successful sync.
