# TEN-221 — [P1] When the review read fails the report drops the calibration curve and the withheld-item disclosure and says nothing
status: Backlog
url: https://linear.app/tenken/issue/TEN-221/p1-when-the-review-read-fails-the-report-drops-the-calibration-curve

**What breaks.** The server review fetch has no identity gate, no timeout, no retry and no failure state. When it fails, `review` stays null, the calibration section falls back to bundled practice keys that match no operational item id, and every bin is empty, so the section renders nothing. The <issue id="95fc8cea-f3e5-4ea9-bcf7-6478176a79f3" href="https://linear.app/tenken/issue/TEN-68/frontend-must-render-the-withheld-arm-of-redacteditem-and-decide-what">TEN-68</issue> withheld-item disclosure disappears with it. An error state is rendered as an empty state.

**Evidence.**
`apps/web/app/report/page.tsx:217-230`:

```ts
fetchServerReview(reportAttemptId)
  .then((r) => { if (!cancelled && r) setReview(r); })
  .catch((err: unknown) => console.warn("[ailx report] review keys unavailable", err));
```

`calBins` (`:232-242`) falls back to `t2AnswerKeys(locale)`; `calibrationBins` drops unknown ids (`packages/report/src/calibration.ts:71-72`), so the guard at `:462` (`calBins.some((b) => b.n > 0)`) renders nothing. `WithheldItems` (`:470-472`) is gated on `review`.

**Blast radius.** Every hosted report where the review read races identity, stalls or blips. A shortened deck is reported at its shortened length with no mark, which is exactly what <issue id="95fc8cea-f3e5-4ea9-bcf7-6478176a79f3" href="https://linear.app/tenken/issue/TEN-68/frontend-must-render-the-withheld-arm-of-redacteditem-and-decide-what">TEN-68</issue> forbids. Silent, so nobody reports it.

**Fixed when.** The failure has a state and the T2 card says the answer key could not be read, so the calibration curve and the item-count check are not shown, with a test that fails the review fetch and asserts the sentence.
