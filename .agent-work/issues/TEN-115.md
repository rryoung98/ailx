# TEN-115 — Pause during T2 destroys the item on screen and scores it as a miss
status: Backlog
url: https://linear.app/tenken/issue/TEN-115/pause-during-t2-destroys-the-item-on-screen-and-scores-it-as-a-miss

`packages/tracks/t2-discrimination/src/Runner.tsx:397-416` + `apps/web/app/exam/page.tsx:749-793`.

`TrackUIProps` carries no `paused` flag, so T2's fixed-exposure `setInterval` keeps ticking behind the pause veil. Reproduced with a probe against the real `ExamPage`: seed t2, Start the deck, Pause, advance 60s -> `responded: {choice: -1, confidence: 0}`. `scoring.ts:186-190` counts `-1` as a miss on a signal item and a false alarm on a noise item. The lapse notice expires after 1600ms behind the veil, so the candidate never learns.

Meanwhile the pause dialog (`exam/page.tsx:873`) says "The track clock is stopped. Content is hidden while paused; your work is kept."

Do: add `paused: boolean` to `TrackUIProps` and have every runner freeze its timers and its latency anchor on it. (Or refuse a pause while a timed item is live and say so on the control - but (a) also fixes exposure-anchor drift across a pause.)
