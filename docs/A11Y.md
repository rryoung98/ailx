# AILX Web — Accessibility (WCAG 2.1 AA) status

Scope: `apps/web/**` and the four track runner packages (`packages/tracks/*/src/**`).

Method: manual checklist review against WCAG 2.1 AA, plus contrast ratios
recomputed from the tokens that actually ship in `apps/web/app/globals.css`
(WCAG relative-luminance formula; the same math is enforced by
`apps/web/test/a11y.test.tsx`), plus the jsdom regression tests listed at the
end.

**How to read this document.** It reports three states and nothing else:

- **pass** — checked against the current source and/or pinned by a named test.
- **unverified** — plausible but NOT re-checked in this pass. Do not quote it
  as conformance evidence.
- **fail / in flight** — a known defect, with the fix status stated.

This file was previously wrong in a dangerous way: it documented a dark theme
and a locale switcher that no longer ship, and prescribed a "dark ink on
accent" button fix that would now measure **2.92:1** and *break* contrast (see
the table below). Anything not re-derived from the source in this pass is
marked *unverified* rather than restated.

## Palette and contrast (recomputed from `globals.css`)

The shipped palette is a light paper theme. Tokens (`globals.css` `:root`):

`--bg #f7f4f2` · `--bg-raised #efeae5` · `--card #ffffff` · `--fg #1a1a1a` ·
`--muted #595650` · `--faint #6b665f` · `--accent #0b6b47` ·
`--accent-dim #bcd9cc` · `--accent-ink #192e19` · `--good #0b6b47` ·
`--warn #9c5f06` · `--bad #b91c1c` · `--distinction #846818` ·
`--merit #4a5568` · `--pass #92400e` · `--participation #6b665f`.

Contrast ratio = (L1 + 0.05) / (L2 + 0.05), L = 0.2126R + 0.7152G + 0.0722B on
linearized sRGB channels. Ratios below are computed from those hex values (2 dp):

| foreground token | on `--bg` | on `--card` | on `--bg-raised` |
|---|---|---|---|
| `--fg` | 15.89 | 17.40 | 14.56 |
| `--muted` | 6.68 | 7.31 | 6.12 |
| `--faint` / `--participation` | 5.20 | 5.69 | 4.76 |
| `--accent` / `--good` | 5.98 | 6.55 | 5.48 |
| `--bad` | 5.91 | 6.47 | 5.41 |
| `--merit` | 6.87 | 7.53 | 6.30 |
| `--pass` | 6.47 | 7.09 | 5.93 |
| `--distinction` | 4.83 | 5.28 | **4.42 ✗** |
| `--warn` | 4.73 | 5.18 | **4.34 ✗** |

Text on the accent fill (`.btn.primary`, `.skip-link`, runner primary buttons —
all of which set `color: #ffffff` over `background: var(--accent)`):

| combination | ratio | verdict |
|---|---|---|
| `#ffffff` on `--accent` | **6.55** | pass (AA and AAA for large text) |
| `#0a0f1e` on `--accent` | **2.92** | **fail** — the fix this doc used to prescribe |
| `--accent-ink #192e19` on `--accent` | **2.22** | **fail** — do not use as button text |
| `#ffffff` on the loader cover `#166b43` | 6.53 | pass (decorative, `aria-hidden`) |

**Do not "fix" white-on-accent buttons.** White text on `--accent` passes at
6.55:1; darkening the text is the failure, not the fix.

### Known contrast limits

- `--warn` (4.34) and `--distinction` (4.42) fall below 4.5:1 **on
  `--bg-raised`** (`#efeae5`, used by `pre`, `blockquote`, `.runner-frame`,
  `.meter`, `.time-bar`). They pass on `--bg` and `--card`. They are used for
  badges and band labels rather than body copy, but nothing enforces that:
  `apps/web/test/a11y.test.tsx` pins `--fg`/`--muted`/`--faint` on all three
  surfaces and `--accent` on `--bg`, and does **not** cover these two.
  **Status: open.** Either lift both tokens or add a test that forbids them on
  a raised surface.
- The persistence-warning banners in `app/exam/page.tsx` still use raw
  dark-theme hex (`#3a1f1f` / `#7a3b3b` / `#ffd9d9`). The pair itself measures
  11.59:1, so this is a theme-consistency defect, not a contrast failure. A
  tokenized replacement (`lib/PersistWarning.tsx`) is in flight.

## Known limits
- **T2 swipe gesture motion** is pointer-driven (1:1 direct manipulation) and
  its card-promotion transition is not gated on `prefers-reduced-motion`. All
  autonomous/looping motion IS gated.
- **Arrow-key handling in the T2 deck** was previously a `window` listener with
  an unconditional `preventDefault()`. It is now bound to the deck root, guards
  modifier keys, composition and text fields, and only calls `preventDefault()`
  when it actually answers. Browse-mode reading elsewhere on the page no longer
  commits a scored answer.
- **WebGL canvas** (T2 image cards) is `aria-hidden` with a DOM-equivalent card
  underneath — by design, noted per WCAG 1.1.1.
- **Neutral alt text** on T2 stimuli ("exam material") is an intentional
  measurement constraint: describing the image would answer the item.
- **Per-second countdowns** (deck exposure, track clock) are visual only; only
  the sub-60s threshold is announced. A candidate who needs more time can pause
  the track clock; fixed item exposures are a declared measurement decision.
- **`--warn` / `--distinction` on `--bg-raised`** — see the contrast section.

## Removed since the previous version of this document
- **Locale switcher.** The UI was removed (`app/exam/page.tsx`: "Locale UI
  removed"); the demo serves the English deck and `SessionConfig.locale` stays
  in the session data. Rows and test claims about switcher `lang` attributes no
  longer describe anything shipping. `lang` on T2 **item content** does still
  ship and is listed above.
- **Dark theme.** All `--faint #5c6575 → #7a8496`, `--fg 16.2`, `--muted 7.64`,
  `--accent 6.15` figures, and the T1/T4 `#7c5cff → #6b46f2` and T2/T3
  "white-on-accent 3.16:1 → dark ink 6.04:1" claims, described a palette that no
  longer exists. They are replaced by the recomputed table above.
