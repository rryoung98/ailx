# AILX Web — Accessibility (WCAG 2.1 AA) Audit & Pass

Scope: `apps/web/**` and the four track runner packages (`packages/tracks/*/src/**`).
Method: manual checklist audit against WCAG 2.1 AA, measured contrast ratios
(WCAG relative-luminance formula, enforced by `apps/web/test/a11y.test.tsx`),
and jsdom regression tests for every fix. Markup/ARIA/token changes only —
no behavioral or scoring changes.

## Checklist by page

## Known limits
- **T2 swipe gesture motion** is pointer-driven (1:1 direct manipulation) and its
  inline card-promotion transition (~340ms) is not gated on
  `prefers-reduced-motion`. The buttons/keyboard path involves the same short
  fling animation. All autonomous/looping motion IS gated.
- **WebGL canvas** (T2 image cards) is `aria-hidden` with a DOM-equivalent card
  underneath — by design, not a gap, but noted per WCAG 1.1.1.
- **Neutral alt text** on T2 stimuli ("exam material") is an intentional
  measurement constraint: describing the image would answer the item.
- **Per-second countdowns** (deck exposure, track clock) are visual only; only
  threshold warnings are announced. A user who needs more time can pause the
  track clock, but fixed item exposures are a declared measurement decision.
- Locale switcher localizes **item content only**; UI chrome remains English
  (`html lang="en"`), stated next to the switcher.

## Regression tests
- `apps/web/test/a11y.test.tsx` — skip link + `#main` target, `html lang`,
  labeled nav, locale-switcher `lang` attrs, measured token contrast ≥ 4.5:1,
  presence of `.sr-only`/`.skip-link`.
- `packages/tracks/t2-discrimination/test/a11y.test.tsx` — deck live region
  content, replay outcome live region, slider labeling with current value,
  SR instructions, `lang` on ja decks / no `lang` noise on en decks.
- `packages/tracks/t3-reasoning/test/reveal.test.tsx` ("T3 reveal a11y") —
  focus lands on the reveal heading; chat log + input labeling.
- `packages/tracks/t4-generative/test/gallery.test.tsx` ("T4 gallery a11y") —
  focus lands on the gallery heading.
